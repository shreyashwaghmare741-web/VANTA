# VANTA

Virtual Autonomous Neural Task Assistant

Think. Understand. Act.

--------------------------------------------------

🧠 What is VANTA?

VANTA is a locally running AI operating assistant built entirely in Python.
It combines a local LLM with native desktop skills to provide a private,
fast and extensible AI assistant.

Unlike cloud assistants, VANTA performs many tasks without sending data
to external servers.
